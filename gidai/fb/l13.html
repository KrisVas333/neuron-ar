Level Up — Leo found Luna’s game too easy, so we make it harder: a game with two obstacles that says WIN or LOSE. "Today I learn to give code two ways."

▶ OPEN THE DECK — L13 Level Up (HTML, press N for notes)

THE TAKEAWAY — WHAT THIS LESSON IS FOR

ELSE = otherwise: a rule has two ways. The kids build a game with two obstacles, hear WIN or LOSE, then make it harder.

  • Technical: bigger kids change the model until they WIN, then code their own IF / THEN / ELSE. Younglings run one icon row and say the OTHERWISE out loud (the icon blocks have no ELSE).
  • Teamwork: four kids, one game. Bigger kids split into two pairs that build and code, and swap at 10:00.
  • Language: every rule out loud: “IF ___ THEN ___ ELSE ___” (younglings: OTHERWISE).

How this code works — explained for mentors

Block by block (PIN 1312 starter)

  1. when Play clicked → set speed 20 % → start motor: the cart drives.
  2. when right lever is up → wait 2 seconds → stop motor: the figure flips the right lever, the cart drives 2 s more, then stops.
  3. if ⟨left lever is up?⟩ then play Win, else play Lose: checked once, when the cart has stopped.

WIN needs both levers up by then. The unchanged model only reaches the right one, so it plays LOSE.

How this code works — explained for mentors

Icon blocks: no IF tile, no ELSE tile

The row reads as a rule: [right lever up] → [stop motor] → [magic sparkle] = IF the lever goes up THEN sparkle. The OTHERWISE exists only out loud: “No sound? OTHERWISE… back to START!”

No tile in the row starts the motor, so the stop tile has nothing to stop: the cart moves only when a kid pushes it.

How this code works — explained for mentors

Blocks the crews can use (PIN 1312 palette)

  • Colour sensor: when [colour] detected · detecting [colour]?
  • Controller: when [left/right] lever is [up] · [left/right] lever is [up]?
  • Control: wait · if … then · if … then … else · wait until
  • Sound: play sound [ ] until done · Single motor: run for N rotations · start / stop motor · set speed

No AND / OR blocks in this palette: two conditions go in two IFs.
